Demo locations
==============

demo-locations.json contains real Ghanaian neighbourhood/city/region names with
approximate sample coordinates and fictional landmark addresses for demo hotels.
The GhanaPost-style codes are synthetic format examples, NOT verified digital
addresses and NOT derived from these coordinates. Do not use for navigation or
mail delivery. Replace with the actual hotel's verified GhanaPostGPS address and
precise coordinates before real use.

Both hotel seed scripts read this shared dataset. The Render seed still skips
existing hotels unchanged. Local database sample locations were updated directly.
